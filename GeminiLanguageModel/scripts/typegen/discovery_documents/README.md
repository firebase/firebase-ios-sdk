# API specifications and overrides

This directory contains the API specification overrides and holds the cached
and upgraded OpenAPI specifications used for generating type-safe Swift data
models.

## Document list

*   [firebasevertexai-overrides.yaml](firebasevertexai-overrides.yaml):
    The manually maintained YAML overrides file defining schema patches
    (`required` properties, `oneOf` unions) and `generatorConfig` settings.
*   `firebasevertexai_discovery_v1beta.json` *(gitignored)*:
    The base Google Discovery Document JSON file describing the Firebase AI
    Logic API, fetched automatically by `upgrade_spec.py` when missing or when
    `--fetch` is passed.
*   `firebasevertexai-openapi.yaml` *(gitignored)*:
    The converted and patched OpenAPI 3.1.0 specification YAML file generated by
    `upgrade_spec.py`. This file is the direct input to `generate_types.py`.

---

## Usage

From `GeminiLanguageModel/scripts/typegen/`:

```bash
# Downloads the Discovery Document if not already cached locally and generates
# firebasevertexai-openapi.yaml:
python upgrade_spec.py

# Force a fresh download of the latest Discovery Document from Google APIs:
python upgrade_spec.py --fetch
```

Do not modify `firebasevertexai-openapi.yaml` directly; instead, make changes
to `firebasevertexai-overrides.yaml` and re-run `python upgrade_spec.py`.
