# Test server recordings

This directory is a placeholder for HTTP recording files generated by
[`google/test-server`](https://github.com/google/test-server).

> [!NOTE]
> When recording files are present, `test-server` uses them in `replay` mode to
> run integration tests deterministically without remote credentials.

## Generating recordings locally

To generate recordings locally for testing:

1. Provide your API key or Firebase project credentials depending on which
   backend(s) you want to test:
   ```bash
   export GEMINI_API_KEY="your-api-key"
   ```

2. Start `test-server` in record mode:
   ```bash
   ./scripts/test_server/run_test_server.sh record
   ```

3. In another terminal, run the integration tests:
   ```bash
   # Run all integration tests:
   swift test --filter IntegrationTests

   # Or run a specific suite:
   swift test --filter ToolCallingIntegrationTests
   ```

All captured interactions will be automatically sanitized and saved to this
directory as SHA-256 keyed JSON files.

For full configuration and workflow details, see the
[`test_server` Guide](../README.md).
