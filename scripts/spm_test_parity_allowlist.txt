# SPM test parity allowlist, read by scripts/check_spm_test_parity.py.

# Lists test source files that no target in the root Package.swift compiles,
# and why. Each entry is one line:
#
#   <glob>  # <category>: <reason>
#
# `**` matches any number of directories, `*` matches within one path
# component, and a trailing `/` matches everything under a directory.
#
# Categories:
#   xcodeproj         Compiled by a checked-in Xcode project that uses the
#                     local package.
#   cmake             Firestore C++ built by CMake.
#   separate-package  Compiled by another Package.swift in this repo.
#   cocoapods         Tests CocoaPods packaging itself; removed with CocoaPods.
#   gap               Compiled only by CocoaPods today; must be ported to SPM
#                     before CocoaPods CI is removed for the product.
#   dead              Compiled by nothing; pending deletion or revival.
#   phase6            Firestore tests built by the CocoaPods Firestore
#                     workspace; ported in Phase 6.
#
# The check fails if an entry matches no file, or if it matches a file that
# SPM compiles. When you add a file to an SPM target, delete or narrow its
# entry here.
